# Phase: research → concept → go / no-go

Produce the sourced scorecard and the concept the whole build will follow. Method: `{{DOCS_DIR}}/RESEARCH.md` in its order, plus BUILD-GUIDE §0 (the concept gate). Write everything into `{{WORK_DIR}}/research.md` (the scorecard, sources with URLs, competitor table, name check, concept) and `{{WORK_DIR}}/concept.md` (BUILD-GUIDE §0: the daily job, home-screen sketch, 3 core non-quiz features, not-a-sibling table, data sources).

1. **Stores first.** For every query a user would type (English, plus French where Quebec is involved), run `node ~/git/app-factory/bin/store-search.mjs "<query>" --country=ca` (and `--country=us` for US audiences). Table every relevant competitor: installs/ratings, rating, last update, price model, what it gets wrong (read a few store reviews with `node -e` against `~/git/reddit-scout/src/stores/{apple,play}.mjs` `reviewsApple`/`reviewsPlay` if useful). A maintained, well-rated, free competitor that already does the core job is a kill unless the gap is concrete.
2. **Demand.** Who, how many, how often, where (sourced numbers or "not found"), what the person does day to day that the app helps with, any recurring trigger (renewal, season, deadline). Use WebSearch/WebFetch; download official sources to `{{WORK_DIR}}/sources/`.
3. **Name.** ≤30 chars, leads with the device name, no trademark/regulator/programme/city crest, no "<X>Prep". Pick the name + 2 fallbacks; the slug (lowercase, letters only, for `win.talnirapps.<slug>` and `talnirappso/<slug>`); check `gh repo view talnirappso/<slug>` is free and neither store search shows an identical name.
4. **4.3(a) concept test.** The honest one-sentence daily job; if it is "take practice tests", that's `kill`. Three core features that are tools (log, tracker, calculator, lookup, alert, map). **No practice/study/exam tab and no question bank** — the account has ~18 exam-prep apps and Termkeep (CE tracker + practice tab) was rejected 4.3(a). Avoid exam/test/quiz/prep wording in names and tabs ("Medical", not "Exams"), and don't make it another renewal/expiry tracker like Termkeep or Ontreminder.
   Then run the past-rejection gate on the concept: `python3 ~/git/common/presubmit/presubmit.py --idea {{WORK_DIR}}/concept.md --json {{WORK_DIR}}/presubmit-idea.json` (compares it with all 61 apps on the account and the App Store, plus a Claude 4.3(a) review). On BLOCK, change the concept and run it again (at most twice); if it still blocks, the verdict is `kill`. Put the final verdict and its `closest_existing` list in the scorecard.
5. **Monetization + size.** Ads/sub/one-time; where in the flow; honest revenue guess vs our history (credential apps earn, generic utilities ≈ $0); build size S/M/L; what needs a backend (prefer none; if one is needed, FastAPI on the VPS per CLAUDE.md).
6. **Locales.** Pick the locales that raise revenue: every language whose speakers have the same pain and can use the app as built (universal job → the high-revenue set: en-US, en-GB, en-AU, es-MX, es-ES, pt-BR, de-DE, fr-FR, fr-CA, it, ja, ko; jurisdiction-bound content → only that jurisdiction's languages, e.g. en-CA + fr-CA). Each extra locale is a store listing that surfaces in that country's search. Say in the scorecard which locales and why, and which content (if any) stays in its source language.
7. **Verdict** `build` / `kill` with the reasons. Off-limits apps and trademark-bound names are kills. If the owner's thread says to proceed despite a concern, respect it and note it.

Result file facts (required): `name`, `alt_names`, `slug`, `bundle_id` (`win.talnirapps.<slug>`), `verdict` (`build`|`kill`), `jurisdiction`, `languages`, `locales` (store locale codes, primary first, e.g. `["en-US","es-MX","pt-BR","de-DE","fr-FR","ja"]`), `core_features` (3 names), `data_sources` (list), `needs_backend` (bool), `monetization`, `build_size`, `banned_terms` (trademarks that must never appear). Status: `ok` for build, `kill` for kill. Summary: the scorecard in ≤300 words (store check result, demand with numbers, name, concept in 3 bullets, risks).
